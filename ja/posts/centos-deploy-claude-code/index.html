CentOS に Claude Code をデプロイする完全ガイド

CentOS 上でゼロから Claude Code をデプロイし、Node.js のインストール、API Key の設定、よくある問題のトラブルシューティングまでカバーします。

1. 環境要件#

  • OS: CentOS 7/8/Stream 9
  • Node.js: v18 以上
  • メモリ: 2GB 以上を推奨
  • ネットワーク: Anthropic API へのアクセスが必要

2. Node.js のインストール#

# 安装 NodeSource 仓库
curl -fsSL https://rpm.nodesource.com/setup_lts.x | sudo bash -

# 安装 Node.js
sudo yum install -y nodejs

# 检查
node -v
npm -v

Node.js のバージョンが低い場合は、nvm でバージョンを管理します：

4

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc
nvm install 20
nvm use 20

3. Claude Code のインストール#

1
2
3
4
5

# 全局安装
npm install -g @anthropic-ai/claude-code

# 检查
claude --version

権限の問題が発生した場合、2 つの解決策があります：

1
2
3
4
5
6

8

# 方案一：sudo
sudo npm install -g @anthropic-ai/claude-code

# 方案二：修改 npm 全局目录（推荐）
mkdir -p ~/.npm-global
npm config set prefix "~/.npm-global"
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

4. API Key の設定#

1
2
3
4
5
6

# 方式一：环境变量（推荐）
echo 'export ANTHROPIC_API_KEY="your-api-key-here"' >> ~/.bashrc
source ~/.bashrc

# 检查
echo $ANTHROPIC_API_KEY

方法 2：claude を直接実行すると、初回起動時に API Key の入力が求められます。

# 启动交互式会话
cd /path/to/your/project

# 直接提问（非交互模式）
claude -p "写一个 Python 脚本，统计当前目录下所有文件的数量"

# 分析代码
cat main.py | claude -p "分析这段代码的潜在问题"

# 查看/修改配置
claude config

# 更新到最新版本
claude update

claude update最新バージョンに更新
