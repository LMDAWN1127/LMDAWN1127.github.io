静态 Pod：kubeadm 的启动原理#

1. 作用#

静态 Pod 不经过 apiserver，把 Pod 清单放进 kubelet 识别的目录即可被拉起，kubeadm 部署的四大组件正是用这种方式实现。

# 指定api的版本号
apiVersion: v1
# 指定资源的类型
kind: Pod
# 指定元数据信息
metadata:
  # 声明资源的名称
  name: xiuxian-v1
# 定义资源的期望状态
spec:
  # 指定Pod调度到哪个节点（静态Pod会忽略该字段，落在文件所在节点）
  nodeName: worker01
  # 指定Pod内的容器
  containers:
    # 指定容器的镜像
  - image: harbor:443/dawn/apps:v1
    # 指定容器的名称
    name: xiuxian
