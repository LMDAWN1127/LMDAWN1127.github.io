Docker 实战：单机网络类型与容器间通信方案详解#

1. Docker 单机网络类型#

1.docker默认有五种单机网络类型#

none:

不分配任何网络，只有本地回环网卡lo。

bridge:

桥接网络，默认容器的网络类型就是桥接网络，会创建虚拟设备对。

host:

使用宿主机网络，不会创建虚拟设备对，而是和宿主机公用网络名称空间。因此此种网络效率最高。

container:

也不会创建新的虚拟机设备对，和一个已经存在的容器使用相同的网络名称空间。

custom network:

自定义网络docker网络类型，需要创建网络，该自定义网络支持基于容器名称访问彼此。相当于内置了DNS功能。

添加hosts解析的方案当容器的IP地址发生变化时，需要手动修改hosts文件;

使用–link关联容器时，被关联的容器重启IP地址发生变化时，会自动更新hosts映射IP;

使用"–link"有个缺陷就是被关联的容器必须运行，若没有运行，则容器无法启动。
