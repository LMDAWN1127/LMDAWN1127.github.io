Docker 实战：macvlan 实现容器跨主机网络互联#

macvlan 是 Linux 内核提供的网络虚拟化技术，它让容器直接拥有宿主机物理网络中的独立 MAC 地址与 IP，从而像物理机一样接入二层网络。本文在两台 Docker 主机（docker01 / docker02）上用 macvlan 驱动创建同网段自定义网络，演示容器如何跨主机二层互通，并补充「macvlan 默认无法连通宿主机与外网」的解决办法，最后用一个 WordPress 多节点部署实战收尾。

7. macvlan的优缺点#

优点#

    1. docker原生支持，无需安装额外插件，配置起来相对简单。
    1. 适合小规模docker环境，例如只有1-3台，如果服务器过多，手动分配IP地址可能会无形之间增加工作量。

缺点#

    1. 需要手动分配IP地址，如果让其自动分配IP地址可能会存在多个主机自动分配的IP地址冲突的情况，到时候还需要人工介入维护;
    1. 本机相同网络(本案例为"dawn_macvlan")的容器之间相互通信没问题，跨主机之间的容器进行通信也没问题，但容器无法与宿主机之间进行通信，也无法连接到外网;
    1. macvlan需要绑定一块物理网卡，若网卡已经被绑定，则无法创建。

如果非要使用macvlan，我们需要手动分配IP地址，无法联网的问题，只需要使用"docker network connect"重新分配一块能够访问外网的网卡即可解决。
