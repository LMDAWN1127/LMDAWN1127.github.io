Dockerfile 构建镜像太大？10 个技巧让镜像瘦身 90%

10 个经过验证的技巧，把 Docker 镜像体积缩小 90% 以上。

1. 选择合适的基础镜像#

# ❌ 太大
FROM ubuntu:22.04          # ~77MB
FROM python:3.11           # ~1GB

# ✅ 推荐
FROM python:3.11-alpine    # ~50MB
FROM python:3.11-slim      # ~130MB

# ✅ 最小
FROM gcr.io/distroless/python3  # ~20MB

2. 使用多阶段构建#

最有效的优化手段：编译阶段用大镜像，运行阶段只复制产物。

 1
 2
 3
 4

10
11

# 阶段 1：编译
FROM golang:1.21 AS builder
WORKDIR /app
COPY . .
RUN go build -o myapp

# 阶段 2：运行
FROM alpine:3.18
WORKDIR /app
COPY --from=builder /app/myapp .
CMD ["./myapp"]

Go 应用从 ~1GB 缩小到 ~15MB。

# ❌ 多个层
RUN apt-get update
RUN apt-get install -y curl
RUN apt-get install -y wget
RUN rm -rf /var/lib/apt/lists/*

# ✅ 合并为一个层
RUN apt-get update && \
    apt-get install -y --no-install-recommends \
        curl \
        wget && \
    rm -rf /var/lib/apt/lists/*

# ❌ 运行镜像里装了编译工具
FROM ubuntu:22.04
RUN apt-get install -y build-essential gcc make cmake
COPY . .
RUN make && make install
CMD ["./myapp"]

# ✅ 编译和运行分离
FROM ubuntu:22.04 AS builder
RUN apt-get install -y build-essential gcc make
COPY . .
RUN make && make install

FROM ubuntu:22.04
COPY --from=builder /app/myapp .
CMD ["./myapp"]

9. 使用 Squash 合并层#

1
2

# 合并所有层为一层，去除中间层的重复文件
docker build --squash -t myapp:slim .

需要在 /etc/docker/daemon.json 中启用 experimental 功能。

# ✅ 优化后（150MB，缩小 87%）
FROM python:3.11-slim AS builder
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir --user -r requirements.txt

FROM python:3.11-slim
WORKDIR /app
COPY --from=builder /root/.local /root/.local
COPY . .
ENV PATH=/root/.local/bin:$PATH
CMD ["python", "app.py"]
