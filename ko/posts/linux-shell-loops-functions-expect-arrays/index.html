3. break, continue, exit 흐름 제어#

  • exit [code]: 전체 스크립트를 즉시 종료하고 상태 코드(0~255)를 반환합니다.

4. expect 기반 대화형 자동화 및 공개키 배포#

비밀번호 없는 로그인이 설정되지 않은 환경에서 expect는 가상 터미널(PTY)을 통해 대화형 도구(ssh, passwd, sftp 등)와의 자동 데이터 송수신을 처리합니다.

1. expect 핵심 명령어#

명령어기능 설명
spawn새로운 프로세스를 시작하고 해당 입출력을 expect가 제어
expect "string"출력을 모니터링하여 특정 대상 문자열(정규식 지원)이 나타날 때까지 대기
send "data\r"사용자 키 입력을 시뮬레이션(\r은 Enter)
interact세션 제어권을 사용자 키보드로 넘겨 수동 조작 허용
expect eof대상 하위 프로세스가 종료되고 EOF 신호가 수신될 때까지 대기
set timeout n매칭 대기 제한 시간(초) 설정 (-1은 무제한 대기)

[root@zabbix ~]# cat << 'EOF' > /root/distribute_key.sh
#!/bin/bash
# 1. 本地生成密钥对
[ ! -f ~/.ssh/id_rsa ] && ssh-keygen -t rsa -N "" -f ~/.ssh/id_rsa

# 2. 目标集群主机列表
CLUSTER_IPS="11.0.1.7 11.0.1.71 101.133.147.148"
PASSWORD="000000"

for ip in $CLUSTER_IPS; do
    echo "正在向 $ip 分发公钥..."
    /usr/bin/expect <<-EOF
        set timeout 5
        spawn ssh-copy-id -o StrictHostKeyChecking=no root@$ip
        expect {
            "yes/no" { send "yes\r"; exp_continue }
            "password:" { send "$PASSWORD\r" }
        }
        expect eof
EOF
done
EOF
[root@zabbix ~]# chmod +x /root/distribute_key.sh

#!/bin/bash
declare -A ip_counts
while read line; do
    ip=$(echo "$line" | awk '{print $1}')
    [ -n "$ip" ] && let ip_counts["$ip"]++
done < /var/log/nginx/access.log

echo "=== Nginx 访问 IP 频次统计 ==="

    printf "%-18s 访问次数: %d\n" "$ip" "${ip_counts[$ip]}"
done

#!/bin/bash
> /tmp/lottery_record.txt
echo "=== 集群运维抽奖系统 (输入 'ok' 结束) ==="

while true; do
    read -p "请输入抽奖人姓名: " name
    [ "$name" == "ok" ] && break
    [ -z "$name" ] && continue

    while true; do
        num=$((RANDOM % 100 + 1))
        # 중복 방지
        if ! grep -qw "$num" /tmp/lottery_record.txt; then
            echo "$num" >> /tmp/lottery_record.txt
            echo "抽奖人: $name, 获得号码: $num"
            break
        fi
    done
done

echo "=== 抽奖排行榜 Top 3 ==="
sort -rnk2 /tmp/lottery_record.txt 2>/dev/null | head -n 3
EOF
