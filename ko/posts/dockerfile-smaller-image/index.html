Dockerfile 이미지가 너무 크다고요? 이미지 크기를 90% 줄이는 10가지 팁

Docker 이미지 크기를 90% 이상 줄이는 검증된 10가지 팁을 소개합니다.

1. 적절한 베이스 이미지 선택#

# ❌ 너무 큼
FROM ubuntu:22.04          # ~77MB
FROM python:3.11           # ~1GB

# ✅ 추천
FROM python:3.11-alpine    # ~50MB
FROM python:3.11-slim      # ~130MB

# ✅ 최소 크기
FROM gcr.io/distroless/python3  # ~20MB
베이스 이미지 크기
ubuntu:22.04 ~77MB
python:3.11 ~1GB
python:3.11-alpine ~50MB
distroless ~20MB

2. 멀티스테이지 빌드 사용#

가장 효과적인 최적화 방법: 컴파일 스테이지에서는 큰 이미지를 사용하고 실행 스테이지에서는 산출물만 복사합니다.

# 스테이지 1: 컴파일
FROM golang:1.21 AS builder
WORKDIR /app
COPY . .
RUN go build -o myapp

# 스테이지 2: 실행
FROM alpine:3.18
WORKDIR /app
COPY --from=builder /app/myapp .
CMD ["./myapp"]

Go 애플리케이션이 ~1GB에서 ~15MB로 축소됩니다.

RUN apt-get install -y curl
RUN apt-get install -y wget
RUN rm -rf /var/lib/apt/lists/*

# ✅ 하나의 레이어로 병합
RUN apt-get update && \
    apt-get install -y --no-install-recommends \
        curl \
        wget && \
    rm -rf /var/lib/apt/lists/*

RUN apt-get install -y build-essential gcc make
COPY . .
RUN make && make install

FROM ubuntu:22.04
COPY --from=builder /app/myapp .
CMD ["./myapp"]

9. Squash로 레이어 병합#

1
2

# 모든 레이어를 하나로 병합하여 중간 레이어의 중복 파일 제거
docker build --squash -t myapp:slim .

/etc/docker/daemon.json에서 experimental 기능을 활성화해야 합니다.

WORKDIR /app

RUN pip install --no-cache-dir --user -r requirements.txt

FROM python:3.11-slim
WORKDIR /app
COPY --from=builder /root/.local /root/.local
COPY . .
ENV PATH=/root/.local/bin:$PATH
CMD ["python", "app.py"]
