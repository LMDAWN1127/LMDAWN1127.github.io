I. Environment preparation
1. OS: CentOS 7.9
2. Memory: 2G for lab, at least 6G for production
3. Disable the firewall and turn off SELinux
4、JDK17

II. Install the JDK
Upload the RPM package

III. Change the Jenkins run user to root
1) Change the run user in the config file
[root@jenkins ~]# vim /etc/sysconfig/jenkins
...
JENKINS_USER="root"
...
2) Change the run user in the service config
[root@jenkins ~]# vim /usr/lib/systemd/system/jenkins.service
...
User=root
Group=root
...
[root@jenkins ~]# systemctl daemon-reload

3) Install font configuration
[root@jenkins ~]# yum -y install fontconfig

IV. Start Jenkins and enable it on boot
[root@jenkins ~]# systemctl start jenkins
[root@jenkins ~]# systemctl enable jenkins

[root@jenkins jenkins]#tar xf /root/jenkins_plu.tar.gz -C plugins/

3. Restart Jenkins to apply
[root@jenkins ~]# systemctl restart jenkins

06. Create a project#

Create a freestyle project and run pwd to see the default working directory Jenkins uses

Note: after Jenkins creates a project, it automatically creates a workspace directory under its home /var/lib/jenkins/, and inside it a directory named after the project.

Subsequently, the code Jenkins pulls from GitLab is stored under this project directory.
